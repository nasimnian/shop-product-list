# ☕ Shop Product List - Online Store Product Catalog

A professional product listing web application built for online stores with advanced search, filtering, and sorting capabilities.

## 📋 Project Overview

This is a fully responsive product catalog application that allows customers to browse products, search in real-time, filter by various criteria, and view detailed product information.

## ✨ Key Features

### 1. Product Listing
- Clean grid layout displaying all products
- Each product shows: image, title, description, price, category, and rating
- Fully responsive on mobile, tablet, and desktop

### 2. Advanced Search
- Real-time search without submit button
- Search by product title
- Debounced search for better performance

### 3. Smart Filters
- **Category filter** - Browse products by category
- **Price range filter** - Set minimum and maximum price
- **Rating filter** - Filter by customer ratings (1-5 stars)
- **Sorting options** - Sort by price (low-high / high-low), rating, and title

### 4. Product Details Page
- High-quality product images with gallery view
- Complete product information
- Brand and category display
- Stock status indicator
- Add to cart functionality (UI ready)

### 5. Related Products
- Automatically shows products from the same category
- Click to view related product details

## 🛠️ Technical Implementation

| Technology | Purpose |
|------------|---------|
| Next.js 16 | React framework with App Router |
| TypeScript | Type safety and maintainability |
| TailwindCSS | Modern, responsive styling |
| TanStack Query | Server state management & caching |
| DummyJSON API | Product data source |

## 📦 Installation & Setup

### System Requirements
- Node.js 18+ 
- npm or yarn package manager

```bash
# 1. Clone the repository
